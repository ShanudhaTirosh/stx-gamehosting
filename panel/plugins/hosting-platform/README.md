# STX Enterprises - Commercial Hosting & Storefront Platform

This custom modular extension provides:
- **Public Storefront** with Sri Lankan Rupee pricing (**LKR**)
- **Automated Invoice Generator** with PDF printing support (`/order/invoice/{uuid}`)
- **Manual Payment Verification Queue** (Commercial Bank, eZ Cash, HelaPay)
- **Live System Status Telemetry** (`/status`)
- **Automated Provisioning Engine** triggered upon staff approval
